Keterangan Layar

Layar 1 — Dashboard Header bulan, 3 kartu ringkasan (Pemasukan / Saldo / Pengeluaran), daftar transaksi berkelompok per hari, tombol FAB (+) untuk catat cepat.
Layar 2 — Tambah Transaksi Toggle Pengeluaran/Pemasukan, display nominal, pilih kategori (5 ikon), kolom catatan opsional, tanggal (default hari ini), keypad angka native-style, tombol Simpan.
Layar 3 — Hapus Transaksi State saat tombol hapus ditekan: item di-highlight merah + konfirmasi inline (Batal / Ya, Hapus) sebelum data dihapus.

User Flow (MVP)

Buka Web → Lihat Dashboard → Tekan "+" → Isi Nominal & Kategori → Simpan ✓ → Kembali ke Dashboard
Target: selesai dalam < 5 detik  ·  No horizontal scroll  ·  Tombol ramah ibu jari
